# GPT-SoVITS-Ciel-Voice-Model-V2

本项目包含基于 **GPT-SoVITS V2** 训练的 **Ciel (学姐)** AI 语音模型。

## 📁 文件说明
- `GPT_weights_v2/`: 存放 .ckpt 格式的 GPT 权重文件
- `SoVITS_weights_v2/`: 存放 .pth 格式的 SoVITS 权重文件
- `config.json`: 模型推理配置文件

## 🛠️ 推理建议
- **底模版本**: GPT-SoVITS V2
- **参考音频**: 建议使用 5-10s 的 Ciel 原声，保持语气平稳。
